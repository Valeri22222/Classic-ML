# Прогнозирование биологической активности химических соединений

## Обзор проекта

**Цель:** Разработать и оценить модели машинного обучения для прогнозирования ключевых показателей биоактивности химических соединений на основе их молекулярных дескрипторов.

Проект охватывает полный пайплайн Data Science:
1.  **Разведочный анализ данных (EDA)**: Изучение распределений, выбросов, корреляций.
2.  **Подготовка данных**: Очистка, трансформация, удаление высококоррелирующих признаков.
3.  **Моделирование**: Обучение и оценка нескольких моделей для задач **регрессии** и **классификации**.
4.  **Оптимизация**: Настройка гиперпараметров лучших моделей с помощью `RandomizedSearchCV`.

В качестве целевых переменных (таргетов) выступают `pIC50`, `pCC50` и `log_SI`, а также их бинарные версии для классификации.

---

## Набор данных

Датасет содержит информацию о **1001** химическом соединении и включает **214 признаков** (молекулярных дескрипторов).

*   **Целевые переменные:**
    *   `IC50, mM` — концентрация ингибирования (полуингибирующая концентрация).
    *   `CC50, mM` — концентрация цитотоксичности.
    *   `SI` — индекс селективности (`CC50 / IC50`).

Для моделирования были созданы трансформированные версии этих переменных (лог-трансформация), которые более устойчивы к выбросам и лучше подходят для машинного обучения.

---

## Основные этапы работы

1.  **Первичная обработка данных (`01_eda.ipynb` & `02_data_preparation.ipynb`):**
    *   Удален неинформативный столбец-идентификатор.
    *   Обработаны пропуски (удалены 3 строки).
    *   Для устранения сильной асимметрии созданы лог-трансформированные таргеты: `pIC50`, `pCC50`, `log_SI`.
    *   Созданы бинарные метки для 4 задач классификации на основе медианы и пороговых значений.
    *   Проведен корреляционный анализ; для борьбы с мультиколлинеарностью удалены признаки с корреляцией > `0.95`. Итоговое число признаков сокращено с 210 до 165.
    *   Выполнена стандартизация признаков с помощью `StandardScaler`.

2.  **Baseline-моделирование (`03_regression_baseline.ipynb` & `04_classification_baseline.ipynb`):**
    *   Обучены 5 моделей с параметрами по умолчанию для каждой задачи:
        *   `LinearRegression` / `LogisticRegression`
        *   `DecisionTreeClassifier` / `DecisionTreeRegressor`
        *   `RandomForest`
        *   `GradientBoosting`
        *   `XGBoost`
    *   Для каждой задачи были выбраны **топ-2 модели** на основе основной метрики (`R²` для регрессии, `F1` для классификации).

3.  **Оптимизация гиперпараметров (`05_regression_tuning.ipynb` & `06_classification_tuning.ipynb`):**
    *   Для выбранных топ-моделей проведена настройка гиперпараметров с помощью `RandomizedSearchCV`.
    *   Метрика оптимизации: `R²` (регрессия) и `F1` (классификация).
    *   Лучшие модели сохранены в папку `artifacts/models/`.

## Результаты

### Регрессия

**Основная метрика: R² (чем выше, тем лучше).**
Модели обучались на лог-трансформированных таргетах (`pIC50`, `pCC50`, `log_SI`).

| Модель              | pIC50 (R²) | pCC50 (R²) | log_SI (R²) |
|---------------------|------------|------------|-------------|
| **Лучшая модель**   | **GradientBoosting (0.52)**  | **RandomForest (0.38)**  | **XGBoost (0.30)** |
| Вторая модель       | RandomForest (0.51)          | GradientBoosting (0.36)   | RandomForest (0.31) |

**Краткий вывод:**
*   Линейная регрессия показала очень низкие результаты (отрицательный R²), что указывает на нелинейную природу данных.
*   Наиболее сложной для прогнозирования оказалась задача предсказания селективности (`log_SI`).

---

### Классификация

**Основная метрика: F1-score (чем выше, тем лучше).**
Модели обучались на 4 бинарных задачах.

| Задача             | Лучшая модель           | F1-score | Вторая модель          | F1-score |
|--------------------|-------------------------|----------|------------------------|----------|
| **IC50 > медианы** | GradientBoosting        | **0.73** | RandomForest           | 0.71     |
| **CC50 > медианы** | XGBoost                 | **0.79** | GradientBoosting       | 0.78     |
| **SI > медианы**   | RandomForest            | **0.67** | DecisionTree           | 0.66     |
| **SI > 8**         | GradientBoosting/XGBoost| **0.72** | -                      | -        |

**Краткий вывод:**
*   Лучшие результаты достигнуты для задачи **CC50 > медианы** (F1 = 0.79), что говорит о хорошей предсказуемости цитотоксичности.
*   Задача **SI > медианы** является самой сложной, что согласуется с результатами регрессии.
*   Ансамблевые методы (RandomForest, GradientBoosting, XGBoost) значительно превзошли простые модели (LogisticRegression, DecisionTree).

## Заключение и выводы

В ходе выполнения проекта были решены задачи регрессии и классификации для прогнозирования биоактивности химических соединений.

-    Наиболее эффективными моделями для данного типа данных являются ансамблевые методы: GradientBoosting, RandomForest и XGBoost. Они значительно превосходят линейные модели и деревья решений.

-    Прогнозирование селективности (SI) является самой сложной задачей, что подтверждается более низкими метриками как в регрессии, так и в классификации.

-   Тщательная предобработка данных, включающая лог-трансформацию таргетов и удаление высококоррелирующих признаков, является критически важным этапом, без которого модели демонстрируют крайне низкую производительность.

-    Оптимизация гиперпараметров позволила незначительно улучшить качество некоторых моделей (например, XGBoost для CC50), но в большинстве случаев baseline-модели показали результаты, близкие к оптимизированным, что говорит об их устойчивости.
